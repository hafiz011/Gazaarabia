FIX 3: CART STOCK RACE CONDITION PREVENTION
================================================================================
STATUS: COMPLETE

Files Created:

    - Uses Prisma $transaction for atomicity
    - Prevents race condition between check and order creation

Files Modified:
  + src/app/api/front-end/orders/route.ts
    - Line 8: Added import validateStockInTransaction
    - Line 375-388: Added stock validation before order creation
    - Returns 400 if stock insufficient

    - Line 9: Added import validateStockInTransaction
    - Line 423-439: Added stock validation before order creation
    - Same protection for guest users

Race Condition Protection:
  BEFORE: No protection - concurrent orders could oversell
  AFTER:  Atomic validation prevents any overselling

    1 item in stock, 2 concurrent orders for 1 item each
    BEFORE: Both orders placed -> -1 inventory
    AFTER:  One succeeds, one rejected with "Insufficient stock"
